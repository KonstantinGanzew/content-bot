# 🔍 Диагностика проблемы бота

Если бот перестал присылать посты, выполните следующие шаги для диагностики:

## 1. Быстрая проверка

```bash
# НАЧНИТЕ С ЭТОГО! Быстрый тест всей системы
quick_test.bat
# или
venv\Scripts\python.exe quick_test.py
```

Покажет работает ли парсер и находит ли он посты.

## 2. Проверка базы данных

```bash
# Посмотрите содержимое базы данных  
venv\Scripts\python.exe show_database.py
```

## 3. Ручной запуск парсинга

```bash
# Запустите один цикл парсинга
manual_parse.bat
# или
venv\Scripts\python.exe manual_run.py
```

Это покажет:
- Сколько постов найдено
- Есть ли новые посты
- Возникают ли ошибки

## 4. Очистка базы данных (если нужно)

```bash
# Если нужно начать заново
clear_db.bat
```

## 5. Полный запуск бота

```bash
# Основной запуск
venv\Scripts\python.exe main.py
```

## 🎯 Возможные проблемы:

### A. Код не запускается
- Проверьте синтаксис: `check_syntax.py`
- Переустановите зависимости: `pip install -r requirements.txt`

### B. Парсер не находит посты
- Проверьте работу сайта JoyReactor
- Убедитесь что фильтрация не блокирует все посты
- Проверьте селекторы в парсере

### C. Посты не отправляются в Telegram
- Проверьте токен и chat_id в настройках
- Убедитесь что все посты не были отправлены ранее

### D. Ошибки с видео
- Проверьте что видео файлы не превышают 50MB
- Убедитесь что формат видео поддерживается

### E. Видео не отправляются

Если видео файлы не находятся или не отправляются:

1. **Проверьте лимиты размера**:
   - Изображения: максимум 10MB  
   - Видео: максимум 50MB

2. **Проверьте поддерживаемые форматы**:
   - Видео: MP4, WebM, AVI, MOV, MKV, FLV
   - Убедитесь что MIME-тип правильно определяется

3. **Проверьте поиск видео**:
   - Парсер ищет видео в `<video>` тегах
   - В ссылках `<a href="...">`  
   - В data-атрибутах (`data-webm`, `data-video`)
   - По всему HTML тексту (regex поиск)

4. **Включите debug логирование**:
   ```python
   import logging
   logging.getLogger('parsers.joyreactor_parser').setLevel(logging.DEBUG)
   ```

5. **Возможные проблемы**:
   - JoyReactor изменил структуру HTML
   - Видео находятся в новых местах (скрипты, iframe)
   - Нужны дополнительные селекторы для поиска

### F. Проблемы с кириллическими URL

Если видео не отправляются из-за кириллических символов в URL:

1. **Симптомы**:
   - Ошибка "Не удалось получить информацию о медиа"
   - URL содержит русские буквы (например: `/гифки-азиаты-ресторан/`)

2. **Исправление** (уже реализовано):
   - Добавлено автоматическое кодирование URL в функциях `_get_media_info()` и `_download_media()`
   - Кириллические символы теперь правильно обрабатываются
   - **Fallback стратегия**: если закодированный URL не работает (404), автоматически пробуется оригинальный URL

3. **Пример исправленного URL**:
   - Оригинал: `https://site.com/pics/гифки-азиаты-ресторан.webm`
   - Кодированный: `https://site.com/pics/%D0%B3%D0%B8%D1%84%D0%BA%D0%B8-...`
   - При 404: автоматический возврат к оригинальному URL

4. **Логи для диагностики**:
   ```
   🔗 Закодированный URL: https://.../%D0%B3%D0%B8%D1%84...
   ⚠️ Файл не найден (404): закодированный URL
   🔄 Пробуем оригинальный URL...
   ✅ Fallback URL работает: оригинальный URL
   ```

5. **Если файл полностью недоступен**:
   - Некоторые файлы могут быть удалены с сервера JoyReactor
   - В этом случае бот автоматически пропускает такой пост
   - Логируется: `⏭️ Пропускаем пост - файл недоступен`
   - Это нормальное поведение - бот продолжает работать с остальными постами

### G. Фильтрация комментариев

Парсер автоматически исключает контейнеры-комментарии:

1. **Что фильтруется**:
   - Контейнеры содержащие `<div class="comment-content">`
   - Сами контейнеры с классом `comment-content`
   - Любые вложенные элементы комментариев

2. **Логирование**:
   ```
   🚫 Отфильтровано контейнеров-комментариев: 15
   Найдено потенциальных контейнеров постов: 25
   ```

3. **Преимущества**:
   - Исключаются ответы и комментарии к постам
   - Отправляются только основные посты с медиа контентом
   - Уменьшается спам в Telegram канале
