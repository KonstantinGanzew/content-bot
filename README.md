# Парсер-бот для JoyReactor и Telegram

Модульный парсер-бот для автоматического парсинга картинок с JoyReactor и отправки их в Telegram группу. Архитектура позволяет легко добавлять новые источники контента.

## Возможности

- 🚀 Автоматический парсинг постов с JoyReactor
- 📱 Отправка изображений в Telegram группу/канал
- 📥 **Умная обработка изображений**: скачивание → проверка → отправка → очистка
- 🗄️ База данных для отслеживания отправленных постов
- ⚙️ Модульная архитектура для добавления новых ресурсов
- 📊 Логирование и мониторинг
- 🔄 Планировщик с настраиваемыми интервалами
- 🛡️ Защита от дублирования и проверка размеров/форматов
- 🔧 Умная система предотвращения дубликатов
- 🚫 Фильтрация нежелательного контента

## Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repo_url>
   cd parser-bot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env` с настройками:**
   ```env
   # Настройки Telegram Bot
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_CHAT_ID=your_chat_id_here

   # Настройки парсинга
   PARSER_ENABLED=true
   PARSER_INTERVAL=300

   # Настройки логирования
   LOG_LEVEL=INFO

   # Путь к базе данных
   DATABASE_FILE=data/sent_posts.json
   ```

## Настройка Telegram Bot

1. **Создайте бота через @BotFather:**
   - Откройте Telegram и найдите @BotFather
   - Выполните команду `/newbot`
   - Следуйте инструкциям и получите токен

2. **Получите Chat ID:**
   - Добавьте бота в группу/канал
   - Отправьте сообщение в группу
   - Перейдите по ссылке: `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
   - Найдите `chat.id` в ответе

## Обработка изображений

Бот использует умную систему обработки изображений:

### Процесс отправки:
1. **📊 Проверка** - получение размера и типа изображения
2. **📥 Скачивание** - сохранение во временную папку
3. **✅ Валидация** - проверка размера и формата  
4. **📤 Отправка** - загрузка в Telegram через локальный файл
5. **🗑️ Очистка** - автоматическое удаление временного файла

### Преимущества:
- ✅ Более стабильная отправка через локальные файлы
- ✅ Проверка изображений до отправки
- ✅ Контроль размеров файлов
- ✅ Автоматическая очистка временных файлов
- ✅ Лучшая обработка ошибок

### Поддерживаемые форматы:
- JPG/JPEG
- PNG  
- GIF
- WebP

### Тестирование:
```bash
# Тест скачивания (без отправки в Telegram)
test_download.bat

# Полный тест с отправкой
manual_parse.bat
```

## Предотвращение дубликатов

Бот использует многоуровневую систему защиты от дубликатов:

### 🔧 Система дедупликации:
1. **Улучшенная генерация ID** - комбинированные хеши (URL + заголовок + время)
2. **Фильтрация в парсере** - отслеживание ID и изображений в рамках сессии  
3. **Проверка базы данных** - двойная проверка перед отправкой
4. **Защита в планировщике** - дополнительные проверки в отправщике

### 📊 Диагностика дубликатов:
```bash
# Полная диагностика дубликатов
fix_duplicates.bat

# Тест системы исправлений
test_duplicates_fix.bat

# Диагностика в реальном времени
diagnose_dup.bat
```

### 🚫 Фильтрация контента:

Автоматическая фильтрация нежелательных постов:
- Посты с "отличный комментарий" 
- Другие настраиваемые фразы
- Конфигурируется в `config/constants.py`

```python
# Управление фильтрацией
CONTENT_FILTERS = {
    'JOYREACTOR': {
        'FILTER_ENABLED': True,  # Вкл/выкл фильтрацию
        'BLOCKED_PHRASES': [
            'отличный комментарий',
            'прекрасный комментарий',
            # ... добавьте свои фразы
        ]
    }
}
```

### 🛠️ Инструменты диагностики:
- `fix_duplicates.py` - анализ и исправление дубликатов
- `diagnose_duplicates.py` - детальная диагностика 
- `test_duplicates_fix.py` - тест системы исправлений
- `test_filter_content.py` - тест фильтрации контента

## Добавление новых ресурсов

Для добавления нового ресурса:

1. **Добавьте константы в `config/constants.py`:**
   ```python
   PARSERS = {
       'JOYREACTOR': {...},
       'NEW_RESOURCE': {
           'BASE_URL': 'https://new-resource.com',
           'TAG_URL': 'https://new-resource.com/category',
           'USER_AGENT': '...',
           'REQUEST_DELAY': 2,
           'IMAGE_SELECTORS': {
               'POST_CONTAINER': '.post',
               'IMAGE': 'img',
               'POST_LINK': 'a[href*="/post/"]'
           }
       }
   }
   ```

2. **Создайте парсер в `parsers/`:**
   ```python
   from .base_parser import BaseParser, PostData
   from config.constants import PARSERS
   
   class NewResourceParser(BaseParser):
       def __init__(self):
           config = PARSERS['NEW_RESOURCE']
           super().__init__(config['BASE_URL'])
           # Реализуйте методы parse_posts и get_post_details
   ```

3. **Добавьте парсер в `scheduler.py`:**
   ```python
   self.parsers = {
       'joyreactor': JoyReactorParser(),
       'new_resource': NewResourceParser()
   }
   ```

## Конфигурация

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота | **Обязательно** |
| `TELEGRAM_CHAT_ID` | ID чата/группы | **Обязательно** |
| `PARSER_ENABLED` | Включить парсинг | `true` |
| `PARSER_INTERVAL` | Интервал парсинга (сек) | `300` |
| `LOG_LEVEL` | Уровень логирования | `INFO` |
| `DATABASE_FILE` | Путь к БД | `data/sent_posts.json` |

### Настройки в constants.py

- `MAX_POSTS_PER_RUN` - максимум постов за цикл
- `MAX_IMAGE_SIZE` - максимальный размер изображения
- `SUPPORTED_FORMATS` - поддерживаемые форматы
- `REQUEST_DELAY` - задержка между запросами

## Логирование

Логи сохраняются в папке `logs/`:
- `parser_bot_YYYYMMDD.log` - общие логи
- `errors_YYYYMMDD.log` - только ошибки

## База данных

База данных отправленных постов хранится в JSON файле для предотвращения дублирования.
